# TX Digital Cleaner — releases

Finished builds of TX Digital Cleaner by Tink Xtra. The app's **Updates** page reads the
newest release here to tell you when a new version is out, then downloads it for you.

Each release has:

- `TX-Digital-Cleaner-Windows-<version>.zip` — unzip, then open `TX-Digital-Cleaner-Windows.exe`
- `TX-Digital-Cleaner-Linux-<version>.tar.gz` — unpack, then run `TX-Digital-Cleaner-Linux`
- a `.sha256` file for each, which TX checks before it unpacks anything
